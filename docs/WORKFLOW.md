# Workflow minimo

1. GrillMe solo per ambiguità importanti; registra le decisioni.
2. Architetto: componenti, confini e interfacce.
3. Auditor: causa e fix proposto, senza edit.
4. Programmatore: modifica minima sul branch.
5. Tester: prove pertinenti, regressioni, esito.
6. Orchestratore: verifica evidenze, aggiorna documenti, propone PR.

Il dispatcher e il validatore Python sono previsti, NON ancora implementati. Nessun agente aggiuntivo per lavoro automatizzabile. Rapporto: stato, file, test, blocchi (massimo poche righe).
