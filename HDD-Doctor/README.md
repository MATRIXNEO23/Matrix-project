# HDD-Doctor

Stato: progettazione. Nessun motore di manutenzione implementato.

Scopo: HDD meccanici Windows; diagnostica SMART, analisi, pulizia prudente, deframmentazione pianificata in idle. Priorità assoluta a dati e backup. Nessuna operazione distruttiva automatica.

Codice, test e schemi specifici rimarranno solo in questa cartella. Prima versione: diagnostica in sola lettura.
